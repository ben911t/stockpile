Preconditions & status legend
  • Launch with uv run run.py (or uv run streamlit run options-scanner/run_app.py).
  • Top bar data source = Schwab. Empty quotes → token expired, re-run schwab_auth.py.
  • Mode is the paper flag in options-scanner/config.toml: paper = true → PAPER (nothing sent to broker); paper = false → LIVE (real orders to account …8556, needs an app restart to change).
  • Live orders are gated to market hours (9:30–16:00 ET, Mon–Fri) and use real money — test minimal size (1 contract), far OTM, comfortable limit.
  • Covered calls need 100+ shares held; cash-secured puts need cash (availableFundsNonMarginableTrade).
  • Every placement/close is two-step: a Confirm… button opens a panel, a Place… button actually sends. Verify at your broker after each live test.
  • Legend: No = not yet tested · Success = behaved as expected · Fail = did not (note what happened).

Progress is stored only in this browser (localStorage). Use Download progress to keep a copy (and Import… to restore it in another browser), or Copy updated Markdown to export your results as a markdown table you can paste anywhere.
